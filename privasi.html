Kebijakan Privasi

Terakhir diperbarui: Agustus 2026

Catatan proyek sekolah: LacakPaket dibuat semata-mata untuk keperluan tugas Praktik Kerja Lapangan (PKL) / proyek magang sekolah, bukan layanan komersial.

1. Data yang Kami Proses

Sistem ini hanya memproses nomor resi pengiriman yang kamu masukkan untuk keperluan pelacakan status paket. Kami tidak meminta data pribadi seperti nama, alamat, atau nomor telepon, dan tidak memperjualbelikan data apa pun kepada pihak ketiga.

2. Riwayat Pelacakan

Setiap nomor resi yang kamu cari disimpan sementara di perangkatmu sendiri (localStorage browser) agar mudah dibuka kembali di halaman Riwayat. Data ini tidak dikirim maupun disimpan di server kami — jika kamu membersihkan data browser atau berpindah perangkat, riwayat tersebut tidak akan ikut.

3. Keamanan Data

Karena sifatnya proyek pembelajaran, LacakPaket tidak menerapkan sistem login maupun penyimpanan data pengguna di server. Seluruh data pelacakan tetap berada di sisi perangkatmu masing-masing.

4. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu seiring perkembangan proyek. Jika ada pertanyaan, silakan hubungi kami melalui halaman Kontak.
